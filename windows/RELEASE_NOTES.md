# Drink Water 1.3.0

- Added **Proxy** below the update controls: system settings, direct access, or custom HTTP, HTTPS, and SOCKS5 servers.
- Supports optional proxy credentials, with saved passwords protected for your Windows account. Custom-proxy failures never fall back to direct access.
- Checks for updates once at app startup. Disable **Check for updates at startup** whenever you like. Startup checks notify only when a newer version is available; updates remain optional.
- Preserves reminder, slogan, sound, and Windows startup settings when upgrading. Network preferences are saved separately.
- Updated the English and Hindi website pages for the new features.

From 1.1.0 or 1.2.0, choose **Check for updates**, then **Download version 1.3.0**. Run the installer over your current installation; no uninstall is needed. Installer downloads open in your browser and follow its proxy settings.

Windows 10 version 1809 or later and Windows 11 on x64. The installer is unsigned. `SHA256SUMS.txt` contains its SHA-256 checksum.

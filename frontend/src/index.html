Good to know

A few details,
before your first sip.

What is Drink Water?+

Drink Water is a free, open-source drinking water reminder for Windows. It sits in your system tray and sends notifications at the interval you choose. No account or subscription is needed.

Does it know when I am thirsty or dehydrated?+

No. This app sends reminders on a timer. It does not measure thirst, track water intake, or detect dehydration. For health information, read the NHS guide to dehydration.

Can I use the water reminders offline?+

Yes. Once installed, reminder notifications, custom intervals, and your slogan file work offline. An internet connection is needed to download the app or check for a newer version.

Which versions of Windows does it work on?+

This release targets Windows 10 version 1809 or later and Windows 11 on 64-bit PCs. Windows 7, Windows 8, and 32-bit Windows are not supported.

Does it run all the time?+

It runs in your tray until you choose Quit. Launch at sign-in is optional and can be changed in the tray menu or Windows startup settings. Disabling reminders leaves the app available in your tray.

Can I use my own intervals and slogans?+

Yes. In the tray menu, open Interval and enter 1–1440 whole minutes. Under Notification slogans, turn Random slogans on to shuffle messages, or off to use the first. Edit slogan list opens your local text file; save one slogan per line and your edits apply at the next reminder.

Does it collect my data?+

The app connects to this website to check for updates at startup or when you choose Check for updates, sending its installed version. You can disable startup checks in the tray menu. It has no accounts or telemetry. Preferences and logs stay on your PC. This website has no tracking scripts or cookies; your theme choice is saved only in your browser.

How do I update the app?+

Right-click the glass and choose Check for updates. If a newer version is available, choose Download version and run the installer. It upgrades your existing installation and keeps your preferences. From version 1.3.0, an optional startup check also notifies you about newer releases. Updates are never forced. No uninstall is needed.

Can I configure a proxy just for this app?+

Yes. Open Proxy below the update controls. Choose Use system proxy, No proxy (direct), or Custom proxy. Custom mode supports HTTP, HTTPS, and SOCKS5, a hostname or IP address, a port, and an optional username and password. Apply the settings to use them for the next update check. A failed custom proxy does not fall back to a direct connection. Installer downloads open in your browser and use its own network settings.

Will Windows show an installer warning?+

The current release is unsigned, so Windows may show an unknown-publisher or SmartScreen prompt. The download comes from the project's GitHub release, which also includes a SHA-256 checksum for verification. We are applying to the SignPath Foundation for code signing; approval is pending. See the code signing policy.

Is there a Linux version?+

This release is for Windows. You can follow development on GitHub.

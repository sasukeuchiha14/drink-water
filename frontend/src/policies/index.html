Drink Water is a Windows reminder app maintained by Hardik Garg. This page describes how the current app handles information and how releases are distributed.

Privacy policy · Code signing policy

Privacy policy

Information on your PC

The app has no user accounts, advertising, or usage telemetry. Reminder settings, slogan text, network preferences, and diagnostic logs are stored in %LOCALAPPDATA%\DrinkWater. These files are not uploaded by the app. They are retained when the app is uninstalled and can be removed manually after quitting the app.

If you configure a proxy, its server, port, and username are saved locally. Saved proxy passwords are protected with Windows Data Protection for the current Windows account and are used to authenticate to the configured proxy. They are not sent to the project's update service.

Update checks

By default, the app checks for updates once when it starts. It also checks when you choose Check for updates. Turn off Check for updates at startup in the tray menu to stop automatic checks; you can still check manually. Updates are optional.

Checks contact drinkwater.hardikgarg.me, with drink-water.hardikgarg.me as a fallback. The request includes the installed version in its URL and the app's user-agent header. Like other network requests, it exposes the connecting IP address, request time, and standard connection information to the hosting provider. The update service reads public release information from GitHub.

Installer downloads open GitHub in your browser. GitHub and its download infrastructure process those requests under their own privacy policies. Browser downloads use the browser's network settings.

The website

The project does not include advertising or analytics scripts. Your theme choice is saved in browser local storage. Netlify hosts the website and update endpoint and may process normal web request logs and provide platform features. Provider processing and retention are governed by the providers' policies; this project does not promise a separate retention period for their logs.

See the Netlify privacy statement and GitHub privacy statement.

Questions

Contact the maintainer through the project repository. Do not post passwords, proxy credentials, or other personal information in public issues.

Code signing policy

Current status: unsigned. We are applying to the SignPath Foundation for open-source code signing. Approval has not been granted, and current downloads must not be treated as SignPath-signed releases.

If accepted, signing will use SignPath.io with a certificate issued to SignPath Foundation. The intended attribution is: “Free code signing provided by SignPath.io, certificate by SignPath Foundation.” This describes the proposed arrangement, not current sponsorship.

Responsibilities and release process

Project author, reviewer, and designated release approver: Hardik Garg. Changes from other contributors are reviewed by the maintainer. Multi-factor authentication is required for maintainer access to GitHub and SignPath.

Releases are built from the public repository using GitHub-hosted GitHub Actions runners. Under the proposed signing process, each release requires approval before signing. Only the project's own binaries and installer components will be submitted for signing; upstream components retain their existing signatures. Signed artifacts will be verified before checksums and release downloads are published.

See the build history, release downloads, and SignPath Foundation requirements.
